Methods

Each check asks one public source one question about a journal. The harvest runs once a month, keeps every response it relied on, and publishes the results as a dated JSON file{% if run %} (the latest is {{ run.label }}){% endif %}.

Reading the results

Every check returns one of five results.

  • {{ badge("pass") }} The record exists and agrees with what we know about the journal.
  • {{ badge("warn") }} The record exists, but something in it is out of date, mismatched or close to lapsing.
  • {{ badge("fail") }} The source has no record, or the record shows a lapse.
  • {{ badge("unknown") }} The source didn't answer, or we don't have the identifier (usually an ISSN) needed to ask it.
  • {{ badge("na") }} The check doesn't apply: DOAJ for a subscription journal, or domain expiry for a journal on a publisher's platform.

I don't combine the checks into a single score. Each of the three areas shows how many of its checks a journal met out of the checks that applied to it, and the journal's page shows the response behind each result, with a fingerprint (SHA-256) of the full response so a result can be matched to the exact record it came from.

A site that refuses automated requests, an API that times out, or a journal with no ISSN on file gets “unknown,” because none of those says anything about the journal. Before a month's results go up I check by hand for the errors a harvest is most likely to make: an ISSN that is registered to some other serial, a journal that has moved while its old address still answers, and a record that matched on title alone.
